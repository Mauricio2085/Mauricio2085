# ¡Hola! Soy José Mauricio Ocampo

Soy **Ingeniero Electrónico** con experiencia en **automatización industrial**, pero actualmente estoy enfocado en **desarrollo de software con JavaScript**. Me apasiona la tecnología y estoy construyendo proyectos que combinan mis conocimientos en electrónica con el desarrollo web.

### Tecnologías que uso
- **Frontend:** React.js, TailwindCSS
- **Backend:** Node.js, Express.js
- **Bases de datos:** PostgreSQL
- **Otros:** Git, Linux (WSL), GIS con ArcGIS Pro

### Proyectos destacados
- [**Smart-Pocket (Frontend)**](https://github.com/Mauricio2085/Smart-Pocket-v1)

Aplicación web para la venta de productos nuevos y saldos mediante tarjetas de presentación interactivas, con opción de contacto directo a través de **WhatsApp**. Desarrollada con **React.js** y estilizada con **Tailwind CSS**, ofrece una experiencia rápida y responsiva para los usuarios.



- [**Smart-Pocket (Backend)**](https://github.com/Mauricio2085/Smart_Pocket_Backend)

API REST que gestiona la autenticación de usuarios y el control de inventario en **Smart-Pocket**. Construida con **Node.js**, **Express** y **PostgreSQL**, implementa **JWT** para autenticación segura y manejo avanzado de errores con **Boom.js**, garantizando eficiencia y seguridad en cada solicitud.
